# BuildWithAIs

[English](https://github.com/BuildWithAIs/) | **简体中文**

**和 AI 一起，把想法做成有用的工具。**

这里是 BuildWithAIs。我们探索 AI 如何参与软件开发、融入日常工作，并把实践沉淀为开源工具和教程。从更自然的语音输入，到辅助工作的 Agent，再到自己动手构建 Agent，我们希望让更多人用得上，也看得懂、改得动。

## 从这里开始

| 项目 | 做什么 | 适合你，如果你想…… |
| --- | --- | --- |
| [Voice Key](https://github.com/BuildWithAIs/voicekey) | 本地优先的桌面语音输入工具，按住快捷键说话，松开后将文字输入当前应用。 | 用语音代替打字，减少输入的负担。 |
| [WorkLens](https://github.com/BuildWithAIs/worklens) | 面向企业工作场景的本地优先工作 Agent，关注 Jira、Confluence、GitHub 等协作环境。 | 探索 AI Agent 如何融入日常工作。 |
| [Learn Agents from Pi](https://github.com/BuildWithAIs/learn-agent-from-pi) | 从 Pi Agent 的架构实践出发，逐步构建 Coding Agent 的中英双语教程。 | 理解 Agent 的工作原理，并动手实现一个。 |

## 我们关注什么

- **从实际需求出发。** 从输入文字、处理工作到编写代码，让每个项目解决具体问题。
- **让使用者保有选择。** 重视本地优先的设计，以及对数据和模型服务的控制。
- **把实践分享出来。** 开放代码，也分享实现思路，让一次尝试成为别人可以继续构建的起点。

## 一起构建

欢迎试用项目，在对应仓库的 Issues 中反馈问题、分享使用场景，或通过 Pull Request 改进代码、文档与翻译。提出新功能时，聊聊你想解决的问题，以及现在是怎么做的。

**从一个小问题开始，一起做出有用的东西。**
