# BuildWithAIs

**English** | [简体中文](https://github.com/BuildWithAIs/.github/blob/main/profile/README.zh-CN.md)

**Build with AI. Make something useful.**

We explore how AI can help us build software and get everyday work done, and share what we learn through open-source tools and tutorials. From voice input to work agents to building your own coding agent, we make projects you can use, understand, and build on.

## Start here

| Project | What it does | Explore it if you want to… |
| --- | --- | --- |
| [Voice Key](https://github.com/BuildWithAIs/voicekey) | Local-first desktop voice input. Hold a hotkey, speak, and release to insert text into your active app. | Spend less time typing and more time expressing your ideas. |
| [WorkLens](https://github.com/BuildWithAIs/worklens) | A local-first work agent for enterprise environments built around tools like Jira, Confluence, and GitHub. | Explore how AI agents can fit into your daily work. |
| [Learn Agents from Pi](https://github.com/BuildWithAIs/learn-agent-from-pi) | A step-by-step coding agent tutorial in English and Chinese, drawing on Pi Agent's architecture. | Understand how agents work and build one yourself. |

## What we care about

- **Start with a real need.** From entering text to working with code, each project starts with a concrete problem.
- **Keep users in control.** We value local-first design and choice over data and model providers.
- **Share the practice.** We share code and the thinking behind it, so each experiment gives someone else a place to start.

## Build with us

Try a project, report a bug or share a use case in its Issues, or contribute code, documentation, and translations through a pull request. For feature ideas, tell us about the problem you want to solve and how you handle it today.

**Start with a small problem. Let's build something useful together.**
